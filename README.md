This project started as a learning experiment — I followed a 2019 Medium article that walked through building apps with the MERN stack, and I decided to expand on it by creating my own full-stack web app for tracking coursework and deadlines. It uses React for the front end, Node and Express for the API, and MongoDB for storing data. I also containerized it with Docker to make deployment easier and more consistent. I treated it like a real-world project by following Agile practices and testing everything with Postman and Studio 3T.
